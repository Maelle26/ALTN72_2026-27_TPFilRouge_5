# 🚆 Supervision d’équipements et suivi d’incidents (Projet RailWatch)
Projet réalisé par Maëlle BITSINDOU et Alexandre POISSONNEAU.

👉 Toutes les informations, instructions de déploiement et de lancement se trouvent dans le [journal.md](./journal.md).

- **Prérequis :** Java 21, MariaDB. Maven n'a pas besoin d'être installé : le projet contient le Maven Wrapper (`mvnw`)
- **Compiler :** `./mvnw compile` (Linux, macOS, Git Bash) ou `mvnw.cmd compile` (invite de commandes Windows)
- **Lancer :** `./mvnw spring-boot:run` puis ouvrir http://localhost:8080
- **Tests :** `./mvnw verify`
- **Application déployée :https://railwatch.spaece.fr/connexion
